# 日志与存储

> 本文件描述**练习日志**（写入条件、字段、允许的操作）与**数据存储**（设置、日志、静态资源的落地方式）。
> 相关：界面上的日志页见 [界面](./UI.md) 的「视图结构」；免责声明（日志不可用于奖项）见项目根目录的 [README](../README.md)。

## 写入条件

日志由通联流程自动写入，判据是状态机的最终状态与上下文。以下条件**全部满足**才写：

1. 状态机进入 `LOGGED`
2. `callsignsConfirmed == true`
3. `rstRx != null`
4. `rstTx != null`
5. `peerEndHeard == true`
6. `userEndSent == true`

> 实现：门槛集中在 `canWriteLog()`（`src/ui/logRecord.ts`），表本身只负责渲染。写入后 `logWritten` 置位，同一次通联不会被写两遍。

## 日志字段

| 字段 | 含义 | 格式 |
|---|---|---|
| `DATE` | 通联日期（UTC） | `YYYY-MM-DD` |
| `TIME_UTC` | 通联时间（UTC），取 `73` / `SK` 结束后的时间点 | `HH:MM:SS` |
| `CALL` | 对方呼号 | 大写 |
| `FREQ_MHZ` | 通联频点（拨轮频率） | `14.0250` |
| `MODE` | 模式 | 固定 `CW` |
| `RST_RX` | 对方发给我的 RST | 三位数字 |
| `RST_TX` | 我发给对方的 RST | 三位数字 |

> `MODE` 恒为 `CW`：`CW-L` / `CW-U` 是接收机在哪一侧解调的操作偏好，不是工作模式，不进日志——真实日志本也是这样。

## 日志操作

- 支持**手动编辑**单条记录
- 支持**清空全部**
- **不支持导出**为 ADIF、CSV、JSON 等任何格式（去争议化：练习日志不能变成可申报的凭证）

日志页常驻一条水印：

```text
练习日志，非真实通联记录，不可用于任何奖项申请。
```

## 数据存储

### 存储方案

- Web：IndexedDB（日志） + localStorage（设置）
- Tauri：SQLite 或 JSON 文件

### 数据类型

| 数据 | 存储 | 说明 |
|---|---|---|
| 用户设置 | localStorage / 配置文件 | 单键 JSON、整份覆盖 |
| 日志 | IndexedDB / SQLite | 自增主键，可改可清，**无导出** |
| 未完成的一次通联 | localStorage（暂存） | 逐行写入，刷新可续；完成或失败即清除 |
| 前缀表 `data/dxcc.json` | 静态资源 | 随应用打包，只读 |

### 降级

所有存储访问都做了保护：没有 IndexedDB（如 jsdom、隐私模式）时日志页提示"无法保存"而不是抛错；localStorage 不可用时暂存与设置退回内存默认值。**界面本身不因存储不可用而失败**。

### 离线运行

- 所有资源本地打包
- 不依赖网络
- Web 原型即可离线运行；最终由 Tauri 打包为桌面 exe（PWA 不做，见 [开发路线](./ROADMAP.md) 的平台一节）
