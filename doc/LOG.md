# 日志与存储

> 本文件描述**练习日志**（写入条件、字段、允许的操作）与**数据存储**（设置、日志、静态资源的落地方式）。
> 相关：界面上的日志页见 [界面](./UI.md) 的「视图结构」；免责声明（日志不可用于奖项）见项目根目录的 [README](../README.md)。

## 写入条件

日志由**操作者亲手写**，不由状态机代写。电台页的录入行里填上对方呼号与两个 RST（见 [快速报文与日志录入](./MESSAGES.md) 的「录入行」），按回车发出结束语（F3）之后，这一行就记进日志。

写入只看一件事：**三个框都齐了**——呼号非空、两个 RST 都是三位有效数字（`599`、`579` 这样）。程序不检查状态机走到了哪一步，也不验证这次通联是否真的成立：真实日志本记的是操作者抄下来的东西，抄错呼号、没等对方签收就收工，都由操作者自己负责。

> 实现：门槛集中在 `canLog()`（`src/ui/entryModel.ts`），落账在 `buildLogRecord()`（`src/ui/logRecord.ts`）——两者都是纯函数，表本身只负责渲染。同一次通联不会被写两遍：写完之后三个框立即清空，下一行是新的一条。

## 日志字段

| 字段 | 含义 | 来源 | 格式 |
|---|---|---|---|
| `DATE` | 通联日期（UTC） | 写日志那一刻 | `YYYY-MM-DD` |
| `TIME_UTC` | 通联时间（UTC） | 写日志那一刻（结束语发完之后） | `HH:MM:SS` |
| `CALL` | 对方呼号 | 录入行（自动转大写） | 大写 |
| `FREQ_MHZ` | 通联频点（拨轮频率） | 写日志那一刻的拨轮 | `14.0250` |
| `MODE` | 模式 | 固定 `CW` | 固定 `CW` |
| `RST_RX` | 对方发给我的 RST | 录入行 | 三位数字 |
| `RST_TX` | 我发给对方的 RST | 录入行（默认 `599`） | 三位数字 |

> 时间与频率都取"落账那一刻"：结束语已经发完，拨轮还没有转走——纸上也是这么记的。

> `MODE` 恒为 `CW`：`CW-L` / `CW-U` 是接收机在哪一侧解调的操作偏好，不是工作模式，不进日志——真实日志本也是这样。

## 日志操作

- 支持**手动编辑**单条记录
- 支持**清空全部**
- **不支持导出**为 ADIF、CSV、JSON 等任何格式（去争议化：练习日志不能变成可申报的凭证）

日志页常驻一条水印：

```text
练习日志，非真实通联记录，不可用于任何奖项申请。
```

## 数据存储

### 存储方案

- 日志：IndexedDB（`src/ui/storage/logStore.ts`）
- 设置：localStorage，单键 JSON（`src/ui/storage/settingsStore.ts`）
- 未完成的一次通联：localStorage 暂存（`src/ui/storage/qsoStaging.ts`）
- 两端**跑的是同一套 Web 存储**，没有原生侧数据库：Tauri 版不写 Rust 存储代码，只用 `src-tauri/tauri.conf.json` 的 `appDirectoriesOverride: "./app-data"` 把 WebView2 的数据目录（含 IndexedDB 与 localStorage）落到 exe 旁的 `app-data/`，所以把 exe 与该目录一起拷走即可带走全部设置与日志。

### 数据类型

| 数据 | 存储 | 说明 |
|---|---|---|
| 用户设置 | localStorage | 单键 JSON、整份覆盖 |
| 日志 | IndexedDB | 自增主键，可改可清，**无导出** |
| 未完成的一次通联 | localStorage（暂存） | 逐行写入，刷新可续；完成或失败即清除 |
| 前缀表 `data/cty.dat` | 静态资源 | 随应用打包，只读 |

### 降级

所有存储访问都做了保护：没有 IndexedDB（如 jsdom、隐私模式）时日志页提示"无法保存"而不是抛错；localStorage 不可用时暂存与设置退回内存默认值。**界面本身不因存储不可用而失败**。

### 离线运行

- 所有资源本地打包
- 不依赖网络
- Web 原型即可离线运行；最终由 Tauri 打包为桌面 exe（PWA 不做，见 [开发路线](./ROADMAP.md) 的平台一节）
