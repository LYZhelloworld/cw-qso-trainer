# 设计文档目录

CW QSO 练习器的设计文档，按能力域拆分，便于分头推进：

| 文档 | 内容 |
|---|---|
| [CW 编解码](./CW-PARSING.md) | 键控输入（直键 / iambic）、摩斯解码（点划 → 字母）、文本 → CW 音频 |
| [报文解析](./MESSAGE-PARSING.md) | 字母文本 → 结构化报文（呼号 / RST / 结束语提取），以及呼号规格与校验 |
| [通联过程](./QSO-PROTOCOL.md) | 报文格式规范、QSO 状态机、别人通联与堆叠点名的规则 |
| [虚拟 HAM 策略](./VIRTUAL-HAM.md) | 呼号前缀与地理位置、生成策略、两类台、堆叠应答、后台互相通联 |
| [音频与电磁环境](./AUDIO-ENVIRONMENT.md) | 音频架构、CW 音调与偏频、S 表、侧音、频段与难度档 |
| [界面](./UI.md) | 电台外壳、瀑布图、各页面、设置面板、辅助模式 |
| [日志与存储](./LOG.md) | 写入条件、日志字段、可做与不可做的操作、数据落地方式 |
| [开发路线与平台](./ROADMAP.md) | 平台选型（Tauri）、五步法分期、后续计划 |

产品目标、免责声明与术语表在仓库根目录的 [README.md](../README.md)。

> 各文档之间用超链接互链，章节不使用编号，新增内容时无需调整序号。文档维护约定见项目根目录的 [AGENTS.md](../AGENTS.md)。
