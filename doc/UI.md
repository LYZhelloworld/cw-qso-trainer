## 平台与技术选型

> **结论（2026-10-14）**：目标产物是 **exe**，路线为 **Web 原型 → Tauri 2 打包 exe**（不用 PWA）。当前 UI 用**原生 TypeScript + Vite、零 UI 框架**直接操作 DOM；这套代码可直接搬进 Tauri 的 WebView，迁移面最小。详见仓库根 `UI-TECH-REVIEW.md` 的「关于做成 exe 程序」一节。

### 候选平台

| 平台 | 优势 | 劣势 |
|---|---|---|
| Web 原型 | 开发快、跨平台、离线可用；Tauri 迁移前可先做验收 | 页面失焦时无法捕获键盘；音频调度需 lookahead |
| Windows / Tauri（最终路线） | 全局键盘、音频延迟低、原生手感、可打包 exe | 需装 Rust 工具链（Windows 还需 VS 生成工具）；未签名 exe 有 SmartScreen 警告 |

> **PWA 不做**：既然目标是 exe，PWA 解决的"网页也能装到桌面"与之重复，优先级下调。

### 快捷键绑定

- Web / Tauri 均使用 `KeyboardEvent.code` 绑定物理键位
- 默认：直键 `Space`；iambic 点键 `KeyZ`、划键 `KeyX`（相邻便于双桨同按，且不与浏览器快捷键冲突），均可在设置页改绑
- 已知限制：Web 页面失焦时无法捕获键盘（迁 Tauri 后解决）

### 建议

先用 **Web 原型**验证音频与状态机逻辑（当前已在做）。  
若 iambic 手感或全局快捷键不达标、或要做到桌面 exe 分发，再迁移至 **Tauri**。  
两者可共用绝大部分 TypeScript 逻辑——核心模块（状态机 / 解码 / HAM / 音频）不碰 DOM，UI 也零框架，迁移只动 `src/ui/**`。

## 日志系统

### 写入条件

以下条件全部满足时自动写入日志：

1. 状态机进入 `LOGGED`
2. `callsignsConfirmed == true`
3. `rstRx != null`
4. `rstTx != null`
5. `peerEndHeard == true`
6. `userEndSent == true`

### 日志字段

| 字段 | 含义 | 格式 |
|---|---|---|
| `DATE` | 通联日期 | `YYYY-MM-DD` |
| `TIME_UTC` | 通联时间（UTC），记录 `73` / `SK` 结束后的时间点 | `HH:MM:SS` |
| `CALL` | 对方呼号 | 大写 |
| `FREQ_MHZ` | 通联频点 | `14.0250` |
| `MODE` | 模式 | 固定 `CW` |
| `RST_RX` | 对方发给我的 RST | 三位数字 |
| `RST_TX` | 我发给对方的 RST | 三位数字 |

### 日志操作

- 支持**手动编辑**
- 支持**清空全部**
- **不支持导出**为 ADIF、CSV、JSON 等格式

### 日志页水印

```text
练习日志，非真实通联记录，不可用于任何奖项申请。
```

## 辅助模式

### 功能

- 显示实时全文
- 显示理想文本，例如 `RST 599`
- 显示发送和接收双方内容
- 不影响日志
- 不标记日志

### 开关

- 用户可随时开启或关闭
- 建议 UI 上显示"辅助模式开启"提醒
- 默认关闭

### 练习意义

- 辅助模式用于熟悉用法
- 关闭后才能有效练习抄收
- 不统计错误率

## UI 设计

### 电台风格外壳

界面按真实电台组织：顶部是常驻的**电台面板**（rig），其下才是二级视图。

- **电台面板（常驻）**：频率大号显示 + 波段 + **模式标签 `CW-L` / `CW-U`**（同时表示模式与边带，且**可点击切换**）；右侧为 **开台/关台** 电源开关与 **设置齿轮**；下方是**频谱瀑布图**（见下节）。
- **模式标签即边带开关**：`CW-L` = 下边带、`CW-U` = 上边带。默认值跟随波段约定（40m 及以下 LSB、20m 及以上 USB），**点击就地翻到另一侧并固定**（40m 上也能切到 `CW-U`），再点翻回。设置里的「CW 边带」可以恢复“自动（跟随波段）”。**无论用哪一侧收，日志记的都是 `CW`**——边带是接收机的操作偏好，不是工作模式。
- **开台 / 关台**：默认**关台**。开台即开始接收与播出，关台即设备待机——避免一打开就被突发的虚拟 HAM 报文惊到。
- **关台只是不接收，不是清空**：虚拟 HAM 在应用启动时就在**所有波段**上生成并开始各自的 CQ 节奏，**与用户是否开机无关**（真实环境不会因为自己下线而大家一起下线）。关台只关闭"接收"这一侧：不接话、不发声、不发射，但频段、台上的台、以及已建立的通联全部原样保留；再开台接着听即可。只有"开着台 + 当前波段"才在接收，其余波段在后台照常运行但不被听到。
- **切换波段**：接收跟着人走，旧波段不会被拆掉（切回去还是原来那个频段与那批台）；波段内调谐只改拨轮频率，不换台。
- **接收通带可调 500 / 250 / 100 Hz**：滤波器以拨轮为中心、宽度可选（默认 500 Hz）。**拨轮 ±带宽/2 之外的台听不到**（CQ 不会被抄收、不发声、也不会被选为通联对象），瀑布图上却照样看得见——这决定了"要先找到并调准信号才能通联"这一基本操作节奏。带宽越窄越是"必须正好停在信号上"。见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)。
- **二级导航**：电台 / 日志 / 关于。

### 瀑布图（波段频谱）

电台面板下方的常驻瀑布图，模拟真实 SDR / 电台的瀑布显示。实现在 `src/ui/waterfall.ts`（canvas），数据来自 `QsoSession.spectrum()`。

- **窗口**：以拨轮频率为中心 **±10 kHz**（共 20 kHz）。时间自上而下流动——每一行是某一瞬间的画面，旧画面向下滑走。
- **通带标记**：画面正中竖着两条细线、中间一层淡色底，标出接收机通带。它固定在正中（显示与滤波器都以拨轮为中心），**宽度随所选滤波带宽变化**——500 Hz 时占窗口的 2.5%，100 Hz 时只有 0.5%。**亮在带外的信号是"在空中但没被接收"**。
- **信号**：每个台按**绝对频率**画成一个亮斑，**亮度随信号强度**变化（强度来自虚拟 HAM 的模拟：由它报告的 RST 决定，并带轻微个体差异）。台站频率对齐 **1 kHz 网格**，所以亮斑总是落在整齐的格子上。
  - 正在**呼叫 CQ** 的台按 CW 键控包络呈现**点划**（不是常亮的竖条）；守听的台只留一条很暗的载波，标记"这里有个台"。
  - 除可通联的台之外，还有若干**装饰性弱背景载波**（`workable: false`），让波段看起来像真实波段那样有内容；它们不参与通联。
- **调谐成曲线**：每一行都用**该行绘制时刻的拨轮频率**计算。转动拨轮时**整个画面不会一起平移**，只有最上方新画出的那几行跟着动，因此调过去的信号会在瀑布上拖出一条斜线/曲线。显示中心另外做了一点**缓动**（约 190 ms），把"一步一跳"抹成平滑曲线。
- **点击调谐**：在瀑布上点击可把拨轮调到该处；落在某个可通联电台附近（±300 Hz）时自动吸附到它。关台时不响应点击（关着的电台不会被点动）。
- **与电源的关系**：瀑布图属于**接收侧**——开台才滚动；关台时画面**冻结**（保留历史）并压暗，标签改为说明"本波段其他电台仍在活动"。开台而通带内无信号时，标签会直接说明"通带内没有信号 · 本波段有 N 个电台"。
- **与音调的关系**：瀑布图是**看到的**频率，耳朵听到的是**拍频音**——没对准的台听起来会**偏调**，而偏的方向由边带决定（见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)）。通联面板的状态行会显示对方**当前实际被听到的音调**，偏频时额外标出偏移量（如"音调 880 Hz · 偏频 +180 Hz"）；一旦调出通带，则改为明说"对方已在通带之外（偏 ±N Hz）"，把"看到的位置"和"听到的音"对上。

### 视图结构

| 视图 | 功能 |
|---|---|
| 电台 | 波段与调谐、波段活动（信号强度 + HAM 列表）、通联面板（收发记录 / 发送 / 电键输入） |
| 日志 | 通联日志列表、编辑、清空 |
| 关于 | 免责声明、版本信息 |
| 设置（齿轮弹出的模态框） | 呼号、音调、WPM、难度、键位、侧音、CW 边带、接收滤波带宽 |

### 电台页

- 四个频段切换与 **±1 kHz 主调谐 / ±100 Hz 微调**（不越出频段边界）
- 信号强度指示（只统计**通带内**的台，与瀑布图给它的亮度一致）与虚拟 HAM 活动列表（每个台标出频率、相对拨轮的偏移、以及自己在"通带内 / 通带外"）
- 未通联时提供两种发起方式（等 HAM 发 CQ / 我发 CQ）；一旦进入通联，则在同一页内显示通联面板（收发记录、发送、电键输入）
  - **监听：等 HAM 发 CQ**——通带内已经有台就直接听它；否则先把拨轮**自动扫到**波段上最近的台再让它呼叫（等价于用手把旋钮扫过去）。波段上没有台时按钮不可用。

### 设置面板

- 用户呼号
- CW 音调
- WPM
- Farnsworth 开关
- **CW 边带**（自动 / CW-L / CW-U；默认「自动」＝按频率约定）
- **接收滤波带宽**（500 / 250 / 100 Hz）
- 难度等级
- 键位绑定
- iambic 模式 A / B
- 点划记忆、自动间隔开关
- 发报侧音开关与音量（默认开、40%；侧音为本地监听音，不受难度档的衰落与干扰影响）

设置以区块组织：**身份 / 音频与速度 / CW 接收 / 通联 / 键位 / 其他**。

## 数据存储

### 存储方案

- Web：IndexedDB（日志） + localStorage（设置）
- Tauri：SQLite 或 JSON 文件

### 数据类型

| 数据 | 存储 |
|---|---|
| 用户设置 | localStorage / 配置文件 |
| 日志 | IndexedDB / SQLite |
| 前缀表 | 静态 JSON，随应用打包 |

### 离线运行

- 所有资源本地打包
- 不依赖网络
- Web 原型即可离线运行；最终由 Tauri 打包为桌面 exe（PWA 不做，见上）
