# 界面（外壳、瀑布图、各页面）

> 本文件描述界面的**结构与交互**：电台风格外壳、瀑布图与滚轮调谐、二级视图、电台页的操作节奏、设置面板，以及"屏幕上不显示什么"这条贯穿全页的原则。
> 相关：日志与存储见 [日志与存储](./LOG.md)；平台路线与分期见 [开发路线](./ROADMAP.md)；调谐与音调的原理见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)；波段活动的来源见 [虚拟 HAM 策略](./VIRTUAL-HAM.md)。

## 电台风格外壳

界面按真实电台组织：顶部是常驻的**电台面板**（rig），其下才是二级视图。

- **电台面板（常驻）**：频率大号显示 + 波段 + **模式标签 `CW-L` / `CW-U`**（同时表示模式与边带，且**可点击切换**）；右侧为 **开台/关台** 电源开关与 **设置齿轮**；下方是**频谱瀑布图**（见下节）。
- **模式标签即边带开关**：`CW-L` = 下边带、`CW-U` = 上边带。默认值跟随波段约定（40m 及以下 LSB、20m 及以上 USB），**点击就地翻到另一侧并固定**（40m 上也能切到 `CW-U`），再点翻回。设置里的「CW 边带」可以恢复"自动（跟随波段）"。**无论用哪一侧收，日志记的都是 `CW`**——边带是接收机的操作偏好，不是工作模式。
- **开台 / 关台**：默认**关台**。开台即开始接收与播出，关台即设备待机——避免一打开就被突发的虚拟 HAM 报文惊到。
- **关台只是不接收，不是清空**：虚拟 HAM 在应用启动时就在**所有波段**上生成并开始各自的 CQ 节奏，**与用户是否开机无关**（真实环境不会因为自己下线而大家一起下线）。关台只关闭"接收"这一侧：不接话、不发声、不发射，但频段、台上的台、以及已建立的通联全部原样保留；再开台接着听即可。只有"开着台 + 当前波段"才在接收，其余波段在后台照常运行但不被听到。
- **切换波段**：接收跟着人走，旧波段不会被拆掉（切回去还是原来那个频段与那批台）；波段内调谐只改拨轮频率，不换台。
- **接收通带可调 500 / 250 / 100 Hz**：滤波器以拨轮为中心、宽度可选（默认 500 Hz）。**拨轮 ±带宽/2 之外的台听不到**（CQ 不会被抄收、不发声、也不会被选为通联对象），瀑布图上却照样看得见——这决定了"要先找到并调准信号才能通联"这一基本操作节奏。带宽越窄越是"必须正好停在信号上"。见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)。
- **二级导航**：电台 / 日志 / 关于。

### 视图结构

| 视图 | 功能 |
|---|---|

## 瀑布图（波段频谱）

电台面板下方的常驻瀑布图，模拟真实 SDR / 电台的瀑布显示。实现在 `src/ui/waterfall.ts`（canvas），数据来自 `QsoSession.spectrum()`。

- **窗口**：以拨轮频率为中心 **±10 kHz**（共 20 kHz）。时间自上而下流动——每一行是某一瞬间的画面，旧画面向下滑走。画面高 **240 px**，按 55 ms 一行算，一次能看到约 **13 秒**的波段历史。
- **通带标记**：画面正中竖着两条细线、中间一层淡色底，标出接收机通带。它固定在正中（显示与滤波器都以拨轮为中心），**宽度随所选滤波带宽变化**——500 Hz 时占窗口的 2.5%，100 Hz 时只有 0.5%。**亮在带外的信号是"在空中但没被接收"**。
- **信号**：每个台按**绝对频率**画成一个亮斑，**亮度随信号强度**变化（强度来自虚拟 HAM 的模拟：由它报告的 RST 决定，并带轻微个体差异）。每个波段常驻 **12–18 个呼叫台**，散布在中央频率 **±25 kHz** 的波段切片上、对齐 **1 kHz 网格**，所以亮斑总是落在整齐的格子上。
  - **只有正在发射的台才有亮斑**：守听中的台（数量远多于频谱能容纳的 51 个槽位，见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「两类虚拟 HAM」）在频谱上根本不存在，除非它正在回答你——那时它就在拨轮那一格。
  - **窗口比波段窄**：台站占 50 kHz，瀑布只看得到 20 kHz。因此画面上永远只有其中一部分，**调谐过程中会不断遇到新台**——这正是真实频谱仪的样子。
  - 正在**呼叫 CQ** 的台按 CW 键控包络呈现**点划**（不是常亮的竖条）；守听的台只留一条很暗的载波，标记"这里有个台"。
  - 除可通联的台之外，还有若干**装饰性弱背景载波**（`workable: false`，8–15 个），让波段看起来像真实波段那样有内容；它们不参与通联。
- **调谐成曲线**：每一行都用**该行绘制时刻的拨轮频率**计算。转动拨轮时**整个画面不会一起平移**，只有最上方新画出的那几行跟着动，因此调过去的信号会在瀑布上拖出一条斜线/曲线。显示中心另外做了一点**缓动**（约 190 ms），把"一步一跳"抹成平滑曲线。
- **滚轮调谐**：鼠标停在瀑布图上滚动滚轮即转动拨轮，一格 **100 Hz**（0.0001 MHz，与 ± 微调按钮同一步长），按住 **Shift 为 1 kHz**（正好落在电台网格上）。滚轮事件被瀑布图接管，不会连带滚动页面；关台时不响应（关着的电台不会被拨动）。
- **调准即听到**：台上的台一直在发 CQ，所以调进通带的那一刻，听到的是它**当前正发到一半**的报文——从中间接上，而不是从头开始，也不是等下一条。如果这条刚好已经发完，就先安静着，几秒后它再开口（间隔见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「CQ 行为」）。调出通带则立刻静音。
- **与电源的关系**：瀑布图属于**接收侧**——开台才滚动；关台时画面**冻结**（保留历史）并压暗，标签改为说明"本波段其他电台仍在活动"。开台而通带内无信号时，标签会直接说明"通带内没有信号 · 窗口里有 N 个信号"。
- **与音调的关系**：瀑布图是**看到的**频率，耳朵听到的是**拍频音**——没对准的台听起来会**偏调**，而偏的方向由边带决定（见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)）。偏了多少、该往哪边调，页面上**不写**：调到通带边缘声音会先变弱、再消失，这就是唯一的提示（所以也没有"音调 880 Hz · 偏频 +180 Hz"这类读数）。

## 电台页

- 四个频段切换与 **±1 kHz 主调谐 / ±100 Hz 微调**（不越出频段边界）
- **S 表**：九段刻度 **S1 – S9**，旁边是读数（`S7`、`S9`、`S9+12`）。读数跟着**最强的那台**走，而不是整条波段，所以它和耳朵听到的一致。三点值得注意：
  - **表针会被滤波器压低**：台站调到通带外时，读数按滤波器的衰减**照 dB 掉**（裙边末端 −26 dB ≈ 掉 4 个 S 单位），掉出裙边后读数变成「—」。
  - **表针一直在动**：每个信号都有自己的 **QSB 慢衰落**（十几秒一周期的两路叠加，按呼号定相位），所以即使拨轮不动、波段没人呼叫，读数也会缓慢起伏。这是它**独立于页面重绘按 150 ms 自刷新**的原因——等下一次"CQ 事件"再画，表针就会僵在那里。
  - **没有信号时是「—」不是 S1**：表针不动就是在说"这个窗口里没东西"，比空转的假底噪更有用。
- **没有波段名册**：页面不列出波段上有哪些台、它们在哪一频、叫什么。瀑布图只告诉你"这里有信号"；是谁、叫什么，得调过去自己听（见下方「没有记录，也没有台名」）。
- 未通联时提供两种发起方式（等 HAM 发 CQ / 我发 CQ）；一旦进入通联，则在同一页内显示通联面板（状态、发送、电键输入）
  - **监听：等 HAM 发 CQ**——通带内已经有台就直接听它；否则先把拨轮**自动扫到**波段上最近的台再让它呼叫（等价于用手把旋钮扫过去）。波段上没有台时按钮不可用。
- **堆叠应答**：发 CQ 后有 **2–3 台**先后应答。瀑布图右上角改为「堆叠 ×N」，发送区提示「回复里必须点名，不点名谁也接不上」。**页面不提供「点名 XXX」按钮**，也不标出有几台——谁在应你，得自己抄下来，再把呼号写进回复。点名后其余各台离场，被点名者回 RST 进入正常交换；始终不点名则各台重呼数次后各自离开（详见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「多人应答（堆叠）」）。
- **HAM 互相通联对操作者不可见**：波段上会随机出现两台自己通联（一台呼叫台 + 一台从守听池里出来的应答台，至少 3 台时才有，见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「互相通联（后台）」），但界面**不显示任何提示**——没有名册可以标注这一对、徽标不写「与 X 通联」、瀑布标签与右上角不显示，也没有「调过去旁听」。唯一的线索是你调到那个频率后听到的两边报文。此时**插不进去**：在这个频率上发 CQ 没人应答（那两台继续说自己的），等它们签完 `73`，原来那个呼叫方隔几秒会重新呼叫 CQ。

## 设置面板

设置收进齿轮弹出的模态框，以区块组织：**身份 / 音频与速度 / CW 接收 / 通联 / 键位 / 其他**。

- 用户呼号（输入时即时校验，失焦才提交）
- CW 音调
- WPM 与 Farnsworth 开关 / 速度
- 发报侧音开关与音量（默认开、40%；侧音为本地监听音，不受难度档的衰落与干扰影响）
- **CW 边带**（自动 / CW-L / CW-U；默认「自动」＝按频率约定）
- **接收滤波带宽**（500 / 250 / 100 Hz）
- 难度等级
- 键位绑定（直键 / 点键 / 划键，点后按下要绑定的键）
- iambic 模式 A / B
- 「其他」区块放**恢复默认设置**

## 没有记录，也没有台名

界面刻意不提供两样东西，因为它们正是要练的东西：

- **不回放收发记录**：每条报文只存在于空中，页面上不留历史。你听到什么、发出什么，全靠耳朵和发送框。
- **不显示对方是谁**：波段上没有活动列表，通联面板也没有状态行（不写「对方 JA1ABC」、不写「交换信息中」）。呼号要自己抄下来，再写进回复——堆叠时更是如此。

理由只有一个：一旦屏幕上能回看、能对号，抄收就从"听"变成了"读"。代价是页面少了"确认感"——对方到底抄对没有，只能靠它下一次发过来的报文判断，这正是真实 CW 通联的处境。

因此也没有辅助模式：没有可以显示的原文，也就没有"遮蔽 / 显示"这个开关。

> 通联记录在内部仍然保留（暂存、日志、状态机的簿记都要用），只是不渲染到页面上。
