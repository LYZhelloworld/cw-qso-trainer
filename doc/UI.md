# 界面（外壳、瀑布图、各页面）

> 本文件描述界面的**结构与交互**：电台风格外壳、瀑布图与滚轮调谐、二级视图、电台页的操作节奏、设置面板，以及"屏幕上不显示什么"这条贯穿全页的原则。
> 相关：日志与存储见 [日志与存储](./LOG.md)；平台路线与分期见 [开发路线](./ROADMAP.md)；调谐与音调的原理见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)；波段活动的来源见 [虚拟 HAM 策略](./VIRTUAL-HAM.md)。

## 电台风格外壳

界面按真实电台组织，自上而下是**机头 → 操作屏（S 表 + 频率 / 波段）→ 瀑布图 → 发送框（三种模式共用）→ 免责页脚**，整屏高度固定，只有中间那一段会滚动（`100dvh` 三段式布局）。

- **机头（常驻，一行三格）**：
  - 左上：**RX / TX 徽标**（大写、带方框、绿色 `RX` 表示接收、红色 `TX` 表示发射）→ **波段**（如 `40m`）→ **模式**（`CW-L` / `CW-U`）。三块都带边框，像一排标着字的窗口。
  - 中间：二级导航 电台 / 日志 / 关于。
  - 右上：**设置** 与 **开台/关台** 电源开关。
- **中间操作屏**：一行之内，**S 表贴左、频率居中**——S 表左端与下面的瀑布图对齐，频率仍然是**整个画面的水平正中**（两侧等宽的列，读数不会因为表的长短而偏移），大号等宽字，按 `MHz.kHz.10 Hz` 分组（`14.025.00`，最后一位是 10 Hz），右侧挂单位 `MHz`（单位挂在数字外侧，不参与居中）。频率下方只有一条**波段细带**，再往下就是瀑布图。三种模式共用这一版式：**电键是键盘上的键**，键位与侧音都在设置里配，屏幕上不为它留位置。
- **瀑布图吃掉剩下的高度**：操作屏按内容高度排（只占它需要的那几行），**其余全部给瀑布图**，一直铺到发送框/页脚上面——屏幕上最大的那块永远是波段画面，而不是空白。
- **底部瀑布图**：贴着屏幕下沿，底部带 **kHz 刻度**（正中 `0` = 当前拨轮，左边负数、右边正数，刻度只写数字不写单位，免得最右端那个标签因为多两个字母而对不齐）；**关台时被「设备已关机」的待机窗整块盖住**，开台才露出来。切到日志 / 关于页时瀑布图暂时收起，把高度让给页面。
- **发送框在瀑布图下面，三种模式共用同一个位置**：单行、宽度与瀑布图一致，像一台机器上的报文键入条——你要发的东西和你看波段的那块屏挨在一起。**报文模式**可编辑、带「发送」按钮，Enter 发出；**直键 / 双键模式**同一个框变成**只读回显**：敲出的字符一解码就出现在框里，没有发送按钮，停手自动发出后清空。框的末尾是一个**块状光标**；还没解码的点划以暗色挂在光标前，字符间隔一过就被解出的文字替换——什么时候断字、什么时候补空格，看光标走位就知道。关台时这一条整个收起，不留空档。
- **模式标签即边带开关，且按波段记忆**：`CW-L` = 下边带、`CW-U` = 上边带。每个波段有自己的默认值（40m 及以下 LSB、20m 及以上 USB），**点击就地翻到另一侧，只改当前这个波段**（40m 上也能切到 `CW-U`），再点翻回；切走再切回来，那个波段还是你上次留的模式，而别的波段不受影响。模式记忆只活在本次运行（刷新后各波段回到默认），设置里也不再提供"全局固定边带"——那会让 40m 沿用 20m 的选择。**无论用哪一侧收，日志记的都是 `CW`**——边带是接收机的操作偏好，不是工作模式。
- **开台 / 关台**：默认**关台**。开台即开始接收与播出，关台即设备待机——避免一打开就被突发的虚拟 HAM 报文惊到。
- **关台只是不接收，不是清空**：虚拟 HAM 在应用启动时就在**所有波段**上生成并开始各自的 CQ 节奏，**与用户是否开机无关**（真实环境不会因为自己下线而大家一起下线）。关台只关闭"接收"这一侧：不接话、不发声、不发射，但频段、台上的台、以及已建立的通联全部原样保留；再开台接着听即可。只有"开着台 + 当前波段"才在接收，其余波段在后台照常运行但不被听到。关台时屏幕只剩**压暗的 S 表与频率**，波段与发送框全部收起。
- **切换波段**：接收跟着人走，旧波段不会被拆掉（切回去还是原来那个频段与那批台）；波段内调谐只改拨轮频率，不换台。
- **接收通带可调 500 / 250 / 100 Hz**：滤波器以拨轮为中心、宽度可选（默认 500 Hz）。**拨轮 ±带宽/2 之外的台听不到**（CQ 不会被抄收、不发声、也不会被选为通联对象），瀑布图上却照样看得见——这决定了"要先找到并调准信号才能通联"这一基本操作节奏。带宽越窄越是"必须正好停在信号上"。见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)。
- **二级导航**：电台 / 日志 / 关于（在机头中间那一格）。

### 视图结构

| 视图 | 功能 |
|---|---|

## 瀑布图（波段频谱）

电台面板下方的常驻瀑布图，模拟真实 SDR / 电台的瀑布显示。实现在 `src/ui/waterfall.ts`（canvas），数据来自 `QsoSession.spectrum()`。

- **窗口**：以拨轮频率为中心 **±10 kHz**（共 20 kHz）。时间自上而下流动——每一行是某一瞬间的画面，旧画面向下滑走。**高度占满窗口剩余的部分**（顶部机头、操作屏、发送框与页脚之外全给它，至少 140 px），按 55 ms 一行算，一次能看到几十秒的波段历史。
- **尺寸变了不清屏**：拖窗口、或上面的操作屏多了一行都会让瀑布图变高变矮。已有画面会**原样搬到新尺寸上**（顶端对齐，新露出来的那一截才从黑开始），历史不断；清屏只发生在两件事上——**关台**和**切波段**（见下方「与电源的关系」）。宽度变了则不搬：旧的列已经对不上新的频率轴。
- **底部 kHz 刻度**：画面下沿有一条标尺，正中的 `0` 就是当前拨轮频率，向左为负（`-5`、`-10`），向右为正（`+5`、`+10`）。刻度是**相对偏移**，所以转动拨轮时刻度不动、信号动。**刻度只写数字**：单位挂在最右端那个标签上会让它比其他标签宽，读数就偏出格线，所以 `kHz` 只出现在文档与频率读数里。
- **频率游标**：画面正中只有**一条**竖线，标出当前拨轮频率——真实电台的频谱上就是一条光标，而不是通带的两个边。滤波器宽度（500 / 250 / 100 Hz）是**听感**参数，不画在频谱上：只有落在游标附近（通带半宽内）的台才收得到，带外的台照样看得见（见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)）。
- **信号**：每个台按**绝对频率**画成一个亮斑，**亮度随信号强度**变化（强度来自虚拟 HAM 的模拟：由它报告的 RST 决定，并带轻微个体差异）。每个波段常驻 **12–18 个呼叫台**，散布在中央频率 **±25 kHz** 的波段切片上、位置落在 **10 Hz** 刻度上，所以亮斑**不排成整齐的格子**；两台挨得近时会并成一个亮斑。
  - **只有正在发射的台才有亮斑**：守听中的台（数量远多于频谱同时能站下的台数，见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「两类虚拟 HAM」）在频谱上根本不存在，除非它正在回答你——那时它就在拨轮那个位置上。
  - **窗口比波段窄**：台站占 50 kHz，瀑布只看得到 20 kHz。因此画面上永远只有其中一部分，**调谐过程中会不断遇到新台**——这正是真实频谱仪的样子。
  - 正在**发射**的台按真实的 CW 键控包络呈现**点划**（不是常亮的竖条）；发射一停（守听）就**什么都不画**——没有声音的时刻没有信号，不留"暗载波"表示这里有个台。
  - 除可通联的台之外，还有若干**装饰性弱背景载波**（`workable: false`，8–15 个），让波段看起来像真实波段那样有内容；它们不参与通联。
- **调谐成曲线**：每一行都用**该行绘制时刻的拨轮频率**计算。转动拨轮时**整个画面不会一起平移**，只有最上方新画出的那几行跟着动，因此调过去的信号会在瀑布上拖出一条斜线/曲线。显示中心另外做了一点**缓动**（约 190 ms），把"一步一跳"抹成平滑曲线。
- **滚轮调谐**：鼠标停在瀑布图上滚动滚轮即转动拨轮，一格 **10 Hz**（读数的最小一位），按住 **Shift 为 1 kHz**（粗调，快速跨过几台）。台站本身落在任意 10 Hz 上，所以粗调只能到附近，最后一格得靠耳朵。滚轮事件被瀑布图接管，不会连带滚动页面；关台时不响应（关着的电台不会被拨动）。
- **调准即听到**：台上的台一直在发 CQ，所以调进通带的那一刻，听到的是它**当前正发到一半**的报文——从中间接上，而不是从头开始，也不是等下一条。如果这条刚好已经发完，就先安静着，几秒后它再开口（间隔见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「CQ 行为」）。调出通带则立刻静音。
- **与电源的关系**：瀑布图属于**接收侧**——开台才滚动；**关台即清屏**（画面压暗、历史不留），再开台从当前拨轮处重新画，不会把上一次的旧画面接着往下推。画面上不写字：开着台时只有波形和底部刻度；关台时整块被「设备已关机」的待机窗盖住（窗里有一个「开台」按钮）。
- **切波段是跳变**：换波段等于换了一台接收机，画面**直接清空并从新波段重画**，不做"扫过几个 MHz"的过渡动画。只有**在同一波段里转动拨轮**才有那条调谐曲线。
- **与音调的关系**：瀑布图是**看到的**频率，耳朵听到的是**拍频音**——没对准的台听起来会**偏调**，而偏的方向由边带决定（见 [调谐与偏频](./AUDIO-ENVIRONMENT.md#调谐与偏频听到的音调)）。偏了多少、该往哪边调，页面上**不写**：调到通带边缘声音会先变弱、再消失，这就是唯一的提示（所以也没有"音调 880 Hz · 偏频 +180 Hz"这类读数）。
- **与声音同源**：画面上的亮与暗、耳机里的有与无，读的是**同一份键控表**——正在敲的就亮着，守听时既不响也不画（见 [音频与电磁环境](./AUDIO-ENVIRONMENT.md#键控表唯一的一份真相)）。所以不会出现"有声没信号"或"有信号没声"这种自相矛盾。

## 电台页

- **S 表与频率同一行**：S 表贴左边（与瀑布图左边缘对齐）、频率居中，读数像真实电台那样在余光里看
- **频率**：整个画面水平正中的大号读数，`MHz.kHz.10 Hz` 分组（`14.025.00`），单位 `MHz`
- **波段细带**：频率下方只有四个频段按钮。**没有调谐步进键**——调谐只在瀑布图上做（滚轮），一排 ± 按钮只是第二套更差的调谐方式
- **S 表是一条横条**（不是逐格升高的柱状图标）：
  - **S1–S9 走蓝色**，占横条左侧 60%；**S9 之后走红色**，占右侧 40%、按 60 dB 满格换算（`S9+60` 打满）。也就是说「过没过 S9」不用读数字，看颜色就够。
  - 横条下方是刻度 `S1 S3 S5 S7 S9 +20 +40 +60`，`S9` 那一格正好是蓝红交界，也标得更亮。
  - 读数（`S7`、`S9`、`S9+12`）就是横条上方的全部文字，无声时是 `—`、整条清空。
  - **关台时表针一律不动**：即使频率上正有台在叫，关着的接收机也没有读数（表属于接收机，电源在它上游）。再开台读数原样回来。
  - 它读的是**此刻正在放出来的声音**，不是一条波段的概况：
  - **有声音才有读数**：对方发报时表针抬起；这条报文发完、台回到守听，表针归零（「—」），不会对着空频亮着。
  - **发报时读自己的电键**：按下满格、松开归零（见下方「发报时不接收」）。
  - **滤波器会压低它**：台站调到通带外时读数照 dB 掉（裙边末端 −26 dB ≈ 掉 4 个 S 单位），出了裙边就没有读数。
  - **表针会随 QSB 缓慢起伏**：每个信号有自己的慢衰落，所以即使报文没变，读数也在动。刷新间隔 **60 ms**，为了跟得上电键。
- **没有波段名册**：页面不列出波段上有哪些台、它们在哪一频、叫什么。瀑布图只告诉你"这里有信号"；是谁、叫什么，得调过去自己听（见下方「没有记录，也没有台名」）。
- **随时可以发报**：发报只有瀑布图下方的发送框（报文模式可编辑，电键模式是只读回显）或电键，没有「开始通联 / 监听 / 我发 CQ」。发出去的是什么、有没有人应，由报文内容和当下谁在听决定（见 [QSO 协议](./QSO-PROTOCOL.md) 的「发报即开始」）。
- **电键模式没有「发送完毕」按钮**：一句话说完就停手，**停手 1.5 秒**电键自己收尾——松 PTT、TX 灭、接收机重新打开，报文随即交给波段（谁应、怎么应由报文内容决定）。想接着说下一句，直接再敲就是新的一轮。
- **堆叠应答**：发 CQ 后有 **2–3 台**先后应答。页面**不报台数、不给呼号、不给「点名 XXX」按钮**——谁在应你，得自己抄下来，再把呼号写进回复。点名后其余各台离场，被点名者回 RST 进入正常交换；始终不点名则各台重呼数次后各自离开（详见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「多人应答（堆叠）」）。
- **HAM 互相通联对操作者不可见**：波段上会随机出现两台自己通联（一台呼叫台 + 一台从守听池里出来的应答台，至少 3 台时才有，见 [虚拟 HAM 策略](./VIRTUAL-HAM.md) 的「互相通联（后台）」），但界面**不显示任何提示**——没有名册可以标注这一对、徽标不写「与 X 通联」、瀑布标签与右上角不显示，也没有「调过去旁听」。唯一的线索是你调到那个频率后听到的两边报文。此时**插不进去**：在这个频率上发 CQ 没人应答（那两台继续说自己的），等它们签完 `73`，原来那个呼叫方隔几秒会重新呼叫 CQ。

## 发报时不接收（半双工）

一个电台不能同时收发。发报这条链路上，界面是这样表现的：

- **机头的徽标从绿色 `RX` 翻成红色 `TX`**，发完再翻回来（徽标自己每 120 ms 读一次发射状态，不靠重绘）。
- 报文发出去的瞬间，接收**中断**：正在播的台立刻静音，别的台也不再被抄收。
- **整个频段跟着待机**：本频段里正在发的台会被立刻掐断，新起的 CQ 也不会在你发报期间上机——它们保住自己的位置，等你说完再按节奏重新呼叫。所以发完之后听到的是重新开始的 CQ，不是别人从半句中间接着念。
- 瀑布图上只画**自己**这一个信号、强度拉满，其他信号暂时消失；发完恢复。
  - 这一条**跟着点划通断**：有音就有行，元素之间与字符之间的间隙是空的（一行画的是 55 ms 里发生的事，所以哪怕 25 WPM 的一个点只占 48 ms 也不会被漏掉）。看到的就是刚发出去的那串点划，不是一条实心条带。
- **S 表跟着电键走**：按下满格、松开归零。
- 停手 **1.5 秒**没再敲，就等于这一句说完了：载波落下（`TX` 灭），再过一个尾巴恢复收听；如果通带里还有台在发，就从它当前的位置接上继续。不需要任何按钮。
- **发报没结束就离开**（切到日志 / 关于、换波段、改设置）：载波立刻落下、接收恢复，不留 `TX`。已经发出去的部分不再继续，下一次按键就是新的一轮。
- **回复还没播完也能打断**：按键永远有效。你按下时对方仍在发，它那一路载波会被立刻掐断，从这一帧开始是新的一轮（真电台的 break-in）。不想打断就等它说完——按键不会因为"正在听回复"而失效。

> 这就是为什么"对准频率就有声音"必须配合持续呼叫：接收恢复的那一刻总有东西可听。

## 设置面板

设置收进齿轮弹出的模态框，以区块组织：**身份 / 音频与速度 / CW 接收 / 通联 / 键位 / 其他**。

- 用户呼号（输入时即时校验，失焦才提交）
- CW 音调
- WPM 与 Farnsworth 开关 / 速度
- 发报侧音开关与音量（默认开、40%；侧音为本地监听音，不受难度档的衰落与干扰影响）
- **CW 边带不在这里**：它按波段记忆，在电台面板上点模式标签改（见上文「模式标签即边带开关」）
- **接收滤波带宽**（500 / 250 / 100 Hz）
- 难度等级
- **发报模式**（报文 / 直键 / 双键，默认报文）
- 键位绑定（直键 / 点键 / 划键，点后按下要绑定的键）
- iambic 模式 A / B
- 「其他」区块放**恢复默认设置**

## 没有记录，也没有台名

界面刻意不提供这些东西，因为它们正是要练的东西：

- **不回放收发记录**：每条报文只存在于空中，页面上不留历史。你听到什么、发出什么，全靠耳朵和发送框。
- **不显示对方是谁**：波段上没有活动列表，通联面板也没有状态行（不写「对方 JA1ABC」、不写「交换信息中」）。呼号要自己抄下来，再写进回复——堆叠时更是如此。
- **不报台数、不报结果**：有几台在应你、有没有人应、通联成没成，屏幕上都不说。真实电台本来也不显示这些。

理由只有一个：一旦屏幕上能回看、能对号，抄收就从"听"变成了"读"。代价是页面少了"确认感"——对方到底抄对没有，只能靠它下一次发过来的报文判断，这正是真实 CW 通联的处境。

因此也没有辅助模式：没有可以显示的原文，也就没有"遮蔽 / 显示"这个开关。

> 通联记录在内部仍然保留（暂存、日志、状态机的簿记都要用），只是不渲染到页面上。
