# 音频与电磁环境（真实感模拟）

> 对应设计目标的第三块：音频——模拟真实电磁环境：底噪、CW 音调、以及电磁波忽强忽弱（QSB）、人为/自然干扰（QRM/QRN）。
> 相关：CW 音调的「时序编码」见 [CW 解析与编码](./CW-PARSING.md)；UI 中的音频控制见 [UI 界面](./UI.md)。

---

## 音频处理架构

**结论：Web Audio API 完全够用。**

- 底噪：`AudioBufferSourceNode` 循环播放白/粉噪声
- CW 音调：`OscillatorNode` 生成 700 Hz 正弦波
- QSB 衰落：`GainNode` 包络调制
- QRM / QRN：额外噪声源 + 带通滤波
- 调度精度：lookahead 调度器，128 采样粒度（约 2.9 ms @ 44.1 kHz）

---

## CW 音调

- 默认：**700 Hz**
- 可调范围：**400 – 1000 Hz**
- 波形：正弦波

---

## 频段与频率

仅支持业余无线电四个 CW 频段：

| 频段 | 频率范围（示例） | 步进 |
|---|---|---|
| 7 MHz | 7.000 – 7.040 MHz | 100 Hz |
| 14 MHz | 14.000 – 14.070 MHz | 100 Hz |
| 21 MHz | 21.000 – 21.070 MHz | 100 Hz |
| 28 MHz | 28.000 – 28.070 MHz | 100 Hz |

> 具体范围可按 IARU 区域调整。

调谐方式：

- 键盘上下键或旋钮控件
- 步进可设为 100 Hz / 500 Hz / 1 kHz

## 真实感模拟

### 难度等级

| 等级 | 底噪 | QSB | QRM / QRN | 接收不全概率 |
|---|---|---|---|---|
| 新手 | 低 | 无 | 无 | 0% |
| 进阶 | 中 | 慢衰落 | 偶发 | 1% |
| 硬核 | 高 | 快衰落 | 较多 | 5% |
| 自定义 | 可调 | 可调 | 可调 | 可调 |

### QSB（信号衰落）

- 使用 `GainNode` 包络调制
- 慢衰落：周期 5–15 秒
- 快衰落：周期 1–3 秒
- 深度可调

### QRM / QRN

- QRM：其他 CW 信号干扰
- QRN：大气噪声
- 以额外噪声源 + 带通滤波实现

### 接收不全

- 默认概率 **1% – 5%**，可调
- 触发时虚拟 HAM 发 `AGN?` 或 `QRZ?`
- 要求用户**全文重发**
- 不模拟具体丢失内容

> 注：接收不全的「应对逻辑」属于 [QSO 协议](./QSO-PROTOCOL.md)（状态机 / 虚拟 HAM 行为），此处仅描述音频触发。
