# 音频与电磁环境（真实感模拟）

> 对应设计目标的第三块：音频——模拟真实电磁环境：底噪、CW 音调、以及电磁波忽强忽弱（QSB）、人为/自然干扰（QRM/QRN）。
> 相关：CW 音调的「时序编码」见 [CW 编解码](./CW-PARSING.md)；UI 中的音频控制见 [UI 界面](./UI.md)。

---

## 音频处理架构

**结论：Web Audio API 完全够用。**

- 底噪：`AudioBufferSourceNode` 循环播放白/粉噪声
- CW 音调：`OscillatorNode` 生成 700 Hz 正弦波
- QSB 衰落：`GainNode` 包络调制
- QRM / QRN：额外噪声源 + 带通滤波
- 播放调度：共享单一 `AudioContext` + lookahead 前瞻调度器（`src/audio/player.ts`）。整段报文先渲染一次（保证 QSB/QRM/QRN 在全段连续、无接缝爆音），再按音频时钟分块调度；返回可中断的 `PlaybackHandle`，`stop()` 可在元素边界打断正在发 CQ 的 HAM，使用户能半途插话应答。Node / jsdom 下无 `AudioContext`，播放立即结束且不抛不挂。

## CW 音调

- 默认：**700 Hz**
- 可调范围：**300 – 1200 Hz**
- 波形：正弦波
- 这是**正对频**时听到的音调；对方失谐时听到的是偏移后的音调，见 [调谐与偏频](#调谐与偏频听到的音调)

## 调谐与偏频（听到的音调）

CW 信号在接收机里是一段**拍频音**：与对方频率完全重合时听到的就是上面设定的 CW 音调，失谐几百 Hz 就会听出音调偏移——与 SSB 接收机的偏频同源。实现见 `src/ham/tuning.ts`。

> **这个现象只发生在接收侧。** CW 发射出去的是**断续的等幅射频载波，本身不含音频**；耳机里的音调是接收机的差拍振荡器（BFO）与收到的载波拍频的产物——`f音频 = |f信号载波 − fBFO|`。正常接收时 BFO 故意偏离中频一个侧音频率（即上面设定的 CW 音调），所以正对频听到的就是它；拨轮偏了，等于改变了信号在中频上的落点，差拍频率随之变化。偏到正好与 BFO 同频（差频 0 Hz）时不会有连续音调，只剩下键控通断的「咔哒」声。
>
> 因此**虚拟 HAM 没有任何「音调 / 频偏」字段**：一个想在 7.010 MHz 呼叫的台，无论它自己的侧音设成多少，信号就落在 7.010 MHz——偏移完全由我们这边的拨轮决定。同一个 `freqHz` 同时决定瀑布位置、明暗强度与是否偏调。

设拨轮频率 `D`、对方频率 `F`、设定音调 `P`：

- **USB（20m 及以上）**：`听到的音调 = P + (F − D)`——往上调拨轮，音调**变低**
- **LSB（40m 及以下）**：`听到的音调 = P − (F − D)`——往上调拨轮，音调**变高**

约定与限幅：

- 边带按频率划分：**低于 10 MHz 用 LSB，10 MHz 及以上用 USB**（电台面板上显示当前边带）
- 音调夹在 **250 – 1800 Hz**：真实接收机的 CW 滤波通带只有几百 Hz 宽，失谐过大时音符会跑出可听范围
- 用户**自己的发报不受影响**：自己的信号永远正对频，听到的就是精确的设定音调

> 简化（有意）：真实接收机在过零点会把拍频折回，并且完全落在通带之外时会直接听不到；这里保持**单调**映射并夹在可听范围内，让「偏离越多越明显」始终成立——这正是练习「用耳朵调准」的意义。

## 发报侧音（Sidetone）

用户自己发报时听到的本地监听音，由 `src/audio/sidetone.ts` 负责。

- 与 HAM 报文不同，侧音**不走 PCM 渲染**：常驻 `OscillatorNode` + `GainNode` 实时开关，按下即响、松开即停，5 ms 斜坡消除键噪
- 跟随对象：直键跟随按键按下/松开；iambic 只跟随元素阶段，键控器自动插入的字符与单词间隔保持静音
- **不受难度档影响**：QSB / QRM / QRN 发生在信道上，本地监听音始终是干净的
- 频率沿用上面的「CW 音调」设置，音量独立（默认 40%），可在设置页开关
- 无 AudioContext 时（Node、测试环境）静默降级为空操作，不影响发报与单测

## 频段与频率

仅支持业余无线电四个 CW 频段（与实现一致）：

| 频段 | 频率范围（MHz） | 默认 | 步进 |
|---|---|---|---|
| 80m | 3.500 – 3.800 | 3.550 | 1 kHz |
| 40m | 7.000 – 7.200 | 7.025 | 1 kHz |
| 20m | 14.000 – 14.350 | 14.025 | 1 kHz |
| 15m | 21.000 – 21.450 | 21.025 | 1 kHz |

> 边带按频率划分：80m / 40m 用 **LSB**，20m / 15m 用 **USB**（见 [调谐与偏频](#调谐与偏频听到的音调)）。

调谐方式：

- 键盘按钮逐 1 kHz 调谐，或在频谱瀑布图上点击信号直接调谐（详见 [UI 界面](./UI.md)）

## 真实感模拟

### 难度等级

| 等级 | 底噪 | QSB | QRM / QRN | 接收不全概率 |
|---|---|---|---|---|
| 新手 | 低 | 无 | 无 | 0% |
| 进阶 | 中 | 慢衰落 | 偶发 | 1% |
| 硬核 | 高 | 快衰落 | 较多 | 5% |
| 自定义 | 可调 | 可调 | 可调 | 可调 |

### QSB（信号衰落）

- 使用 `GainNode` 包络调制
- 慢衰落：周期 5–15 秒
- 快衰落：周期 1–3 秒
- 深度可调

### QRM / QRN

- QRM：其他 CW 信号干扰
- QRN：大气噪声
- 以额外噪声源 + 带通滤波实现

### 接收不全

- 触发概率见上方「难度等级」表（新手 0% / 进阶 1% / 硬核 5% / 自定义可调）
- 触发时虚拟 HAM 发 `?` 或 `AGN?`（请求全文重发；`QRZ?` 专用于呼号抄错，不在此用）
- 要求用户**全文重发**
- 不模拟具体丢失内容

> 注：接收不全的「应对逻辑」属于 [QSO 协议](./QSO-PROTOCOL.md)（状态机 / 虚拟 HAM 行为），此处仅描述音频触发。
