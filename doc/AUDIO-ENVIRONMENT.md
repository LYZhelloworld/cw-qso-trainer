# 音频与电磁环境（真实感模拟）

> 对应设计目标的第三块：音频——模拟真实电磁环境：底噪、CW 音调、以及电磁波忽强忽弱（QSB）、人为/自然干扰（QRM/QRN）。
> 相关：CW 音调的「时序编码」见 [CW 编解码](./CW-PARSING.md)；UI 中的音频控制见 [UI 界面](./UI.md)。

---

## 音频处理架构

**结论：Web Audio API 完全够用。**

- 底噪：`AudioBufferSourceNode` 循环播放白/粉噪声
- CW 音调：`OscillatorNode` 生成 700 Hz 正弦波
- QSB 衰落：`GainNode` 包络调制
- QRM / QRN：额外噪声源 + 带通滤波
- 调度精度：lookahead 调度器，128 采样粒度（约 2.9 ms @ 44.1 kHz）

---

## CW 音调

- 默认：**700 Hz**
- 可调范围：**300 – 1200 Hz**
- 波形：正弦波

---

## 发报侧音（Sidetone）

用户自己发报时听到的本地监听音，由 `src/audio/sidetone.ts` 负责。

- 与 HAM 报文不同，侧音**不走 PCM 渲染**：常驻 `OscillatorNode` + `GainNode` 实时开关，按下即响、松开即停，5 ms 斜坡消除键噪
- 跟随对象：直键跟随按键按下/松开；iambic 只跟随元素阶段，键控器自动插入的字符与单词间隔保持静音
- **不受难度档影响**：QSB / QRM / QRN 发生在信道上，本地监听音始终是干净的
- 频率沿用上面的「CW 音调」设置，音量独立（默认 40%），可在设置页开关
- 无 AudioContext 时（Node、测试环境）静默降级为空操作，不影响发报与单测

## 频段与频率

仅支持业余无线电四个 CW 频段：

| 频段 | 频率范围（示例） | 步进 |
|---|---|---|
| 7 MHz | 7.000 – 7.040 MHz | 100 Hz |
| 14 MHz | 14.000 – 14.070 MHz | 100 Hz |
| 21 MHz | 21.000 – 21.070 MHz | 100 Hz |
| 28 MHz | 28.000 – 28.070 MHz | 100 Hz |

> 具体范围可按 IARU 区域调整。

调谐方式：

- 键盘上下键或旋钮控件
- 步进可设为 100 Hz / 500 Hz / 1 kHz

## 真实感模拟

### 难度等级

| 等级 | 底噪 | QSB | QRM / QRN | 接收不全概率 |
|---|---|---|---|---|
| 新手 | 低 | 无 | 无 | 0% |
| 进阶 | 中 | 慢衰落 | 偶发 | 1% |
| 硬核 | 高 | 快衰落 | 较多 | 5% |
| 自定义 | 可调 | 可调 | 可调 | 可调 |

### QSB（信号衰落）

- 使用 `GainNode` 包络调制
- 慢衰落：周期 5–15 秒
- 快衰落：周期 1–3 秒
- 深度可调

### QRM / QRN

- QRM：其他 CW 信号干扰
- QRN：大气噪声
- 以额外噪声源 + 带通滤波实现

### 接收不全

- 触发概率见上方「难度等级」表（新手 0% / 进阶 1% / 硬核 5% / 自定义可调）
- 触发时虚拟 HAM 发 `?` 或 `AGN?`（请求全文重发；`QRZ?` 专用于呼号抄错，不在此用）
- 要求用户**全文重发**
- 不模拟具体丢失内容

> 注：接收不全的「应对逻辑」属于 [QSO 协议](./QSO-PROTOCOL.md)（状态机 / 虚拟 HAM 行为），此处仅描述音频触发。
