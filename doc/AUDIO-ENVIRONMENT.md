# 音频与电磁环境（真实感模拟）

> 对应设计目标的第三块：音频——模拟真实电磁环境：底噪、CW 音调、以及电磁波忽强忽弱（QSB）、人为/自然干扰（QRM/QRN）。
> 相关：CW 音调的「时序编码」见 [CW 编解码](./CW-PARSING.md)；界面上的音频控制见 [界面](./UI.md)。

---

## 音频处理架构

**结论：每个台都是一台发射机，边发边敲；所有台混进一条总线，由接收机滤波。**

虚拟台不"放录音"，它**发报**：先把要说的内容组织成报文文本，按 WPM 拆成点划，然后**实时敲到频率上**——和真实的电键一样，这一刻有载波、下一刻没有。耳机里听到的、S 表指着的、瀑布图上画着的是**同一件事**，因为它们读的是同一份键控表。

三层结构（`src/audio/bandSynth.ts`）：

| 层 | 是什么 | 由谁决定 |
|---|---|---|
| 发射机 `Tx` | 一个台的载波：振荡器 + 键控增益 | 报文、WPM、该台频率与强度 |
| 混音总线 | 全波段汇入的一条总线：所有 `Tx` ＋ QRN 噪声 ＋ QRM 幽灵台 | 难度档 |
| 接收机 | 每台一道通带增益，外加一个总音量 | 拨轮频率、边带、滤波带宽 |

**发射机（`Tx`）**：`振荡器 → 增益 → 总线`。振荡器跑的不是射频频率，而是**此刻会听到的拍频**——`P ± (F − D)`（见 [调谐与偏频](#调谐与偏频听到的音调)）。键控直接排在增益上：每个点/划是一段上扬、每个间隔是一段落下，起落各 5 ms 斜坡消键噪；发完最后一个元素，增益归零，台回到守听。**没有声音就是没有声音**，不是"音量调小"。

**混音总线**：一条共用 `GainNode`。QRN 是一段循环播放的噪声 buffer（首尾相接、无接缝），QRM 是几个只开不关的幽灵振荡器、各自带慢速抖动。台站与噪声在这里**相加**，互不压制。

**接收滤波只压信号，不压噪声**：每台的通带增益 `passbandGain(偏移)` 乘在**它自己的增益**上，总线噪声保持原电平。所以把拨轮转开，信号是"沉进噪声里"，而不是"连噪声一起变小"——这正是裙边末端不可用的原因（见 [接收通带](#接收通带可调-500--250--100-hz中心就在拨轮上)）。

**拨轮一动，声音就跟着动**：偏移变了，台站的振荡器频率与通带增益同时改（参数平滑约 30 ms，不是硬切）。滚动滚轮时听到的是一段连续的滑音，与真机转动拨轮一致；带外的台**照常在发**，只是增益为 0——听不到而已，瀑布图上照样看得见。

**半双工**：发报时总线整体静音（只留侧音），发完再等一段尾音（`TX_TAIL_MS`）才放开——发报期间听不到别人。这段时间里瀑布图也只画自己那一个信号（见 [界面](./UI.md) 的「发报时不接收」）。

**「调准就听到」是自然结果**：台站一直在发，所以把拨轮停进它通带的那一刻，听到的就是它**正发到一半**的那条报文——不必算"从第几秒开始放"，报文本来就在总线上跑着，接收机只是终于放它进来了。调出通带则立刻安静（增益归零），台站自己照发不误。

**时间轴**：键控以**音频时钟**（`AudioContext.currentTime`）为轴排程，界面上的"此刻"问的是同一个时钟。浏览器没有 `AudioContext` 时（Node / 测试环境）退化为可手动推进的虚拟时钟，行为一致、可断言。

### 键控表：唯一的一份真相

音频、S 表、瀑布图都从**同一份键控表**取答案，只是问的问题不同：

| 读者 | 问什么 | 得到 |
|---|---|---|
| 音频 | 每个元素的起止时刻 | 排成增益斜坡，实时敲 |
| 瀑布图 | `keyed(t)`：此刻载波在不在 | 在就画，不在就不画——精确到点划 |
| S 表 | `onAirAt(t)`：这条报文还在不在发 | 整条报文期间保持抬起，不在点划之间抖动 |

两个问题分开是有意的：**频谱仪可以诚实到毫秒，表针却有惯性**。按键调速会让指针每秒抖十几次，真实表针不会这样闪，所以它只判断"这份报文还在不在发"。

表里的每一行都是「谁、什么频率、从什么时候开始、点划多长」，没有第二处簿记。这样就不会出现"听得见却没有读数"或"没声音还亮着"——旧实现里音频按录音放、S 表读播放簿记、瀑布图另有一套推算，正是三处各说各话的根源。

> 侧音仍是独立的实时节点（见下方「发报侧音」）：它属于操作者自己，不走总线、不受滤波器与难度影响。

> **迁移中**：`src/audio/render.ts`（整段渲染）与 `src/audio/player.ts`（前瞻调度）是旧路径，按本模型替换后删除；侧音不受影响。

## CW 音调

- 默认：**700 Hz**
- 可调范围：**300 – 1200 Hz**
- 波形：正弦波
- 这是**正对频**时听到的音调；对方失谐时听到的是偏移后的音调，见 [调谐与偏频](#调谐与偏频听到的音调)

---

## 调谐与偏频（听到的音调）

CW 信号在接收机里是一段**拍频音**：与对方频率完全重合时听到的就是上面设定的 CW 音调，失谐几百 Hz 就会听出音调偏移——与 SSB 接收机的偏频同源。实现见 `src/ham/tuning.ts`。

**频率读数就是载波频率。** CW 模式下电台显示的是对方**载波**的频率，不含任何音调补偿：对方在 7.010000 MHz，你把拨轮调到 7.010000、PITCH 设成 700 Hz，听到的就是 700 Hz 侧音——**不需要**自己在读数上再加 700 Hz。改 PITCH 只改侧音高低，不改频率读数。

> **这个现象只发生在接收侧。** CW 发射出去的是**断续的等幅射频载波，本身不含音频**；耳机里的音调是接收机的差拍振荡器（BFO）与收到的载波拍频的产物——`f音频 = |f信号载波 − fBFO|`。正常接收时 BFO 故意偏离中频一个侧音频率（即上面设定的 CW 音调），所以正对频听到的就是它；拨轮偏了，等于改变了信号在中频上的落点，差拍频率随之变化。偏到正好与 BFO 同频（差频 0 Hz）时不会有连续音调，只剩下键控通断的「咔哒」声。
>
> 因此**虚拟 HAM 没有任何「音调 / 频偏」字段**：一个想在 7.010 MHz 呼叫的台，无论它自己的侧音设成多少，信号就落在 7.010 MHz——偏移完全由我们这边的拨轮决定。同一个 `freqHz` 同时决定瀑布位置、明暗强度与是否偏调。

设拨轮频率 `D`、对方频率 `F`、设定音调 `P`：

- **USB（电台显示 `CW-U`）**：`听到的音调 = P + (F − D)`——往上调拨轮，音调**变低**
- **LSB（电台显示 `CW-L`）**：`听到的音调 = P − (F − D)`——往上调拨轮，音调**变高**

### 边带：约定给初始值，用户可点击切换

边带由频率约定给出**初始值**：低于 10 MHz 用 LSB，10 MHz 及以上用 USB。但这不是约束——**电台面板上的模式标签 `CW-L` / `CW-U` 本身就是一个开关**，点一下翻到另一侧（40m 上也能用 `CW-U` 接收），再点一下翻回去。

**边带按波段记忆，跟真机一样**：每个波段各记各的模式，切换波段就换成那个波段的模式，不会把上一个波段的边带带过去；没动过的波段一律用它自己的约定值（40m `CW-L`、20m 及以上 `CW-U`）。所以「第一次开台全部是各波段的默认模式」，之后你改过哪个波段，那个波段就一直记着——直到刷新页面（模式记忆只活在本次运行，不写进设置）。设置里没有「CW 边带」这一项：全局固定值会让 40m 沿用 20m 的选择，正是这条规则要避免的事。

> **日志里永远是 `CW`。** `CW-L` / `CW-U` 是接收机的操作偏好（哪一侧边带解调），不是工作模式；无论用哪一侧收完一次通联，记录都是 `CW`——真实日志本也是这样。

### 接收通带：可调 500 / 250 / 100 Hz，中心就在拨轮上

接收机 CW 滤波器以拨轮频率为中心，宽度可选 **500 Hz（默认）/ 250 Hz / 100 Hz**（设置里的「接收滤波带宽」）：

| 对方相对拨轮 | 听到的 |
|---|---|
| 偏 0 Hz（正对频） | 设定音调——**要收的信号就在通带正中** |
| 通带内（±带宽/2 以内） | `P ± 偏移量`，方向由边带决定，**音量不变** |
| 通带外到 1.5×半宽（裙边） | 音调照旧 `P ± 偏移量`，但**音量一路衰减**，边缘处约 −26 dB |
| 超出 1.5×半宽 | **完全听不到**——不是「变尖 / 变闷」 |

带宽本身就是最直接的难度旋钮：**500 Hz** 时偏 200 Hz 还听得清楚，**250 Hz** 时已经出界（只剩很弱的声音），**100 Hz** 时只有正好停在信号上（±50 Hz）才通联得上——正好与电台页的 **±100 Hz 微调**配套使用。

由此得出三条界面行为：

- **「听得到」与「通联得了」是两件事**：能不能通联，界线是**通带边缘（±带宽/2）**——出了这条线，CQ 不会被抄收、不会成为通联对象，对方也不会应你的呼叫。但**声音还没立刻消失**：滤波器有裙边，它会在接下来的半个带宽里越走越弱，到 `1.5 × 半宽` 才彻底安静（500 Hz 时是 ±375 Hz）。这段 fading 就是给耳朵的信号——「你正在离开可以通联的窗口」。想通联就得把拨轮调回去（滚动滚轮，或用 ± 调谐按钮）。波段上其它台仍在照常呼叫，只是我们没在听它们——瀑布图上依旧看得见。
- **两台永远不会互相干扰**：电台频率以 **1 kHz** 为间距（见 [虚拟 HAM](./VIRTUAL-HAM.md)），而最宽的通带加上两侧裙边也只有 750 Hz，所以一个接收窗口里最多容得下一台。
- **拨轮停在两格之间时谁都收不到**，这是正常的：真实操作里也是这样，得先找到信号。

约定与限幅：

- 音调夹在 **250 – 1800 Hz**：这只是保险丝——最宽（500 Hz）通带下音调最多只会偏离 `P` 一个 ±250 Hz，正常设置下碰不到这两个边界
- 用户**自己的发报不受影响**：自己的信号永远正对频，听到的就是精确的设定音调

**裙边的具体形状**（`passbandGain`，纯函数）：通带内平坦取 1；从半宽到 `1.5 × 半宽` 按**升余弦**从 1 降到 `10^(−26/20) ≈ 0.05`；再往外直接归零。**只压信号，不压噪声与干扰**——底噪、QRM 保持原样，所以信号是"沉进噪声里"，而不是"连噪声一起变小"，这也正是裙边末端不可用的原因。

> 仍然保留的简化：**过零点的拍频折回**没有模拟。真实情况下把拨轮推过对方的载频，音调会先降到 0 再反向升起；这里音调一路降到 250 Hz 就夹住，不做折返。通带内的映射也保持单调。

## S 表（信号强度读数）

电台页的信号强度表读的是**此刻正在放出来的声音**，刻度按 IARU 的 S 表：

| 读数 | 含义 | 对应电平 |
|---|---|---|
| S1 – S9 | 每段 **6 dB** | S9 = **−73 dBm**，S1 = −121 dBm（低 48 dB） |
| S9+N | 强于 S9 的信号 | 比 S9 高 N dB |

- **有声音才有读数**：一条报文只在它真的在发的时候才登记。发完了、台回到守听，表针归零（显示「—」）——宁可指"现在没东西"，也不对着空频亮着。
- **发报时读自己的键**：半双工下听不到别人，表针跟着自己的电键走——按下满格、松开归零。
- **强度由台上报的 RST 推出**——刻意保留的简化（真实链路两个方向互不相关，这里要的是"表针与刚才那句报告对得上"）。同一套刻度在生成侧与读出侧共用（`ham/smeter` 的 `strengthForSUnit`），所以报 `579` 的台在表上就是 **S7**，两处不会各说各话。波段上因此会同时出现 S4 到 S9 的台，而不是全挤在满刻度上。
- **滤波器衰减按 dB 扣**：台站调到通带外，读数照 `passbandGain` 的 dB 值往下走（裙边末端 −26 dB ≈ 掉 4 个 S 单位），出了裙边就没有读数——表针显示"没有信号"，而不是退到 S1。这一步必须加在 dB 域：线性相乘会把整段裙边压进最底一格，正好抹掉操作者最需要看的那个下降过程。
- **表针仍在缓慢呼吸**：每个信号都有按呼号定相位、按难度定深度的 **QSB 慢衰落**（约 17 秒与 7 秒两路叠加），所以一条报文发到一半，读数也在起伏。它和音频里那次 QSB **不是同一个数**：新手难度刻意不给抄收设障碍（声音平稳），但真实表针本来就跟着噪声一起呼吸。
- **谁在发声，表就指谁**：凡是此刻**真的有声音放出来**的台都算——你调到的 CQ、应你点名的堆叠台、甚至频段上另外两台正在自己通联（只要拨轮停在它们那一格）。判定只有一处（`onAirAt`）：录过报文的台按报文时长算，只报「keying 到什么时候」的驱动（堆叠、背景通联）按它报的算。表针因此在**整条报文**期间保持抬起（按键调速会让指针每秒抖十几次，真实表针有惯性，不会这样闪），报文发完才归零；瀑布图则精确到点划，两者用同一个"此刻有没有声"的答案，不会一个有声一个无读数。
- 只有**瀑布窗口内**、且**滤波器还能放行**的台参与比较，同一时刻只显示最强的那一台——真实 S 表也不告诉你有几个信号。

## 发报侧音（Sidetone）

用户自己发报时听到的本地监听音，由 `src/audio/sidetone.ts` 负责。

- 与 HAM 报文不同，侧音**不走 PCM 渲染**：常驻 `OscillatorNode` + `GainNode` 实时开关，按下即响、松开即停，5 ms 斜坡消除键噪
- 跟随对象：直键跟随按键按下/松开；iambic 只跟随元素阶段，键控器自动插入的字符与单词间隔保持静音
- **不受难度档影响**：QSB / QRM / QRN 发生在信道上，本地监听音始终是干净的
- 频率沿用上面的「CW 音调」设置，音量独立（默认 40%），可在设置页开关
- 无 AudioContext 时（Node、测试环境）静默降级为空操作，不影响发报与单测

## 频段与频率

仅支持业余无线电四个 CW 频段（与实现一致）：

| 频段 | 频率范围（MHz） | 默认 | 主调谐步进 | 微调 |
|---|---|---|---|---|
| 40m | 7.000 – 7.200 | 7.025 | 1 kHz | 100 Hz |
| 20m | 14.000 – 14.350 | 14.025 | 1 kHz | 100 Hz |
| 15m | 21.000 – 21.450 | 21.025 | 1 kHz | 100 Hz |
| 10m | 28.000 – 28.500 | 28.025 | 1 kHz | 100 Hz |

> 边带**默认**按频率划分：40m 用 **LSB（显示为 `CW-L`）**，20m / 15m / 10m 用 **USB（显示为 `CW-U`）**；可在电台面板点模式标签切换（见 [调谐与偏频](#调谐与偏频听到的音调)）。

调谐方式：

- 主调谐按钮逐 **1 kHz**（与电台频率网格一致，按一下正好落在某一台上），微调按钮逐 **100 Hz**（用来对准通带边缘、听偏调音色）
- 或在频谱瀑布图上**滚动滚轮**调谐（一格 100 Hz，Shift 为 1 kHz）；瀑布图正中只有一条频率游标，滤波器宽度是听感、不画成两条边线（详见 [界面](./UI.md)）

## 真实感模拟

### 难度等级

| 等级 | 底噪 | QSB | QRM / QRN | 接收不全概率 |
|---|---|---|---|---|
| 新手 | 低 | 无 | 无 | 0% |
| 进阶 | 中 | 慢衰落 | 偶发 | 1% |
| 硬核 | 高 | 快衰落 | 较多 | 5% |
| 自定义 | 可调 | 可调 | 可调 | 可调 |

### QSB（信号衰落）

- 以增益包络调制信号（升余弦，谷底按 depth 衰减，深时可近似静音）—— 实时乘在发射机自己的增益上，不碰总线噪声
- 慢衰落：周期 5–15 秒（进阶档取 10 秒）
- 快衰落：周期 1–3 秒（硬核档取 2 秒）
- 深度可调；新手档**不启用**

### QRM / QRN

- QRM：其他 CW 信号干扰——以若干固定频偏的等幅载波模拟（偏移约 0.25–2 kHz，按难度叠 0–2 个）
- QRN：大气噪声——白噪声
- 两者都直接混进总线**叠加**，不受滤波器增益影响（只有信号被压）

### 接收不全

- 触发概率见上方「难度等级」表（新手 0% / 进阶 1% / 硬核 5% / 自定义可调）
- 触发时虚拟 HAM 发 `?` 或 `AGN?`（请求全文重发；`QRZ?` 专用于呼号抄错，不在此用）
- 要求用户**全文重发**
- 不模拟具体丢失内容

> 注：接收不全的「应对逻辑」属于 [QSO 协议](./QSO-PROTOCOL.md)（状态机 / 虚拟 HAM 行为），此处仅描述音频触发。
